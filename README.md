## 一、项目背景与痛点终结

Google Antigravity 是一款顶尖的智能体原生（Agentic）桌面开发客户端。目前官方仅提供纯英文交互界面，由于其前端架构基于极为复杂的 React 虚拟 DOM、流式 Protobuf 消息和 Monaco 核心代码编辑器，传统汉化方案常常面临严重困境：

1. **市面 Python 动态注入方案**：
   - 用户必须在本地配置繁琐的 Python 环境与外部依赖包；
   - 每次启动都必须在后台常驻一个黑色命令行窗口（CMD/Terminal），极易误触关闭；
   - 页面初次加载存在明显的英文闪烁（FOUC）与几百毫秒的“跳字延迟”。
2. **粗暴替换 ASAR 方案**：
   - 传统打包往往塞入完整的数兆字节完整 ASAR，不仅文件臃肿（上百兆），而且每次官方静默升级后，旧版补丁极易把官方程序降级回旧版本，引发协议与通信错乱；
   - 孤立短词强行替换，导致“类型 / and select plan...”等生硬中英夹生饭。

为了从根本上终结这些工程痛点，**Antigravity-Hans** 由 **YunLingHUI** 自主研发推出。本项目采用独创的「双模驱动架构」，将原生 C# 单文件管理中心、零依赖 CDP 纯内存注入管道、微创 ASAR 动态打补丁引擎、可视化词条自定义工作台与 2,313+ 条高精词典高度集成，单文件仅 600KB，零环境依赖，开箱即用！

## 三、双模驱动核心技术架构

### 模式一：安全纯内存静默模式 (官方推荐 · 零封号风险)
- **核心定位**：专为对账号安全、官方原版纯净度有极致要求的专业开发者设计。
- **底层原理**：
  1. 本地磁盘上的 `resources/app.asar` **100% 永久保持官方出厂原版**（严格保留官方字节），SHA256 哈希与 Google 官方数字签名毫发无损；
  2. 管理工具通过 Chrome DevTools Protocol (CDP) 调试管道拉起官方程序，利用 .NET 原生 `ClientWebSocket` 管道纯静默建立通信；
  3. 通过 `Page.addScriptToEvaluateOnNewDocument` 与 `Runtime.evaluate` 指令，将纯净汉化引擎直接映射写入渲染进程内存；
  4. 进程在内存中即时完成 DOM 转译，客户端关闭后内存瞬间释放，磁盘零任何残留修改；
  5. **智能动态双向热开关**：管理工具内置动态状态识别，支持在软件运行中随时一键“开启纯内存中文”与“停用切回官方英文”，无需重启客户端，随点随切。

### 模式二：深度固化模式 (原生微创打补丁 · 打开即中文)
- **核心定位**：追求极致加载速度、零毫秒跳字、希望日常直接双击官方桌面快捷方式即可获得全中文体验的用户。
- **底层原理**：
  1. 彻底颠覆传统“覆盖整个 ASAR”的笨拙做法，采用独家 **MiniAsarPatcher 尾部追加算法**，耗时仅 0.05 秒就地修补本地 `resources/app.asar` 中的 `dist/preload.js`；
  2. 补丁内置常数级精准词典哈希映射（Exact Map），并在 TreeWalker 遍历中挂载 `NodeFilter.FILTER_REJECT` 进行整树剪枝，严格避开用户聊天消息流与代码块；
  3. 首次安装自动就地生成 `app.asar.official_backup`，支持随时点击“恢复官方出厂原版”，一秒无损还原。

## 四、独家核心特性

### 1. 原生微创尾部追加打补丁算法 (MiniAsarPatcher)
小工具内嵌代码直接精准解析 Chromium Pickle ASAR 二进制协议。原版全部 1,084 个文件的数据在数据区中的物理位置完全不动，仅将汉化脚本追加在原数据区末尾，重构头部索引树并刷新 SHA256 校验。未来官方客户端静默更新后，小工具直接就地读取最新版的 asar 并微创修补，终生自适应！

### 2. 可视化词库编辑器与免重启即时热生效
- **双 Tab 工作台**：管理小工具内置专属【词条自定义中心】，自动解析 2,313 条原生高精词条；
- **实时模糊搜索**：支持输入英文或中文关键字毫秒级过滤，支持“仅看已自定义”筛选；
- **免重启即时热生效**：点击【保存并热生效 (一键注入客户端)】，小工具通过 WebSocket 实时向当前运行中的客户端窗口发送热重绘指令，**无需重启软件，界面词条当场变成您的自定义中文**！

### 3. 快捷方式全链路智能无痕接管
自动扫描用户桌面快捷方式以及开始菜单，智能注入参数。日常使用完全不需要每次打开管理工具，直接双击桌面上的 Antigravity 官方图标，即可全自动以纯内存中文模式启动！

### 4. 独家 V8 8GB 大内存防崩溃守护
Antigravity 官方客户端底层采用 gRPC-Web/Protobuf 流式通信。当单个会话执行步骤极多（如排查长代码任务）时，V8 引擎在流式解包巨额 Protobuf 二进制流时极易耗尽默认 2GB 内存配额，抛出致命错误 `ConnectError: [unknown] Array buffer allocation failed` 导致整窗黑屏崩溃。  
本工具自动向启动链路注入官方标准参数 `--js-flags="--max-old-space-size=8192"`，将堆内存上限扩展至 8GB，彻底消除千步超长排查会话的崩溃隐患。

### 5. 官方纯净 Quote (Ctrl+L) 布局保护
彻底剔除外挂蓝底“译”字悬浮球，完全清空对上下文浮动容器的 CSS 侵入，100% 恢复官方原生纯净、无挤压、无裁切的 `Quote Ctrl+L` 极简排版。

### 6. 宿主进程零强杀保障
坚决杜绝任何后台静默 `taskkill`，当检测到客户端正在运行时，提供友好提示引导用户正常保存退出，保障当前所有活跃会话通信零中断、账号凭据零损坏。

### 7. 客户端瘦身与缓存清理
智能扫描 Antigravity 的 `Cache`、`Code Cache`、`GPUCache`、`DawnWebGPUCache` 与 `Crashpad/reports`，一键释放高达数百兆至数 GB 的冗余缓存垃圾。

## 五、零封号风险安全合规声明

1. **官方标准通道对接**：
   安全纯内存静默模式所调用的 `--remote-debugging-port` 为 Chromium 与 Electron 官方公开、正规支持的标准开发者通信接口，完全属于官方框架允许的功能范畴。
2. **零核心篡改**：
   纯内存模式下，磁盘上的所有可执行文件、核心动态库及 ASAR 归档均未发生任何单字节更改，完全通过 Google 官方更新程序与数字安全校验。
3. **零隐私嗅探**：
   汉化引擎仅在本地浏览器渲染进程上下文中执行文本节点转译，绝不监听、收集、上传任何用户的输入内容、代码片段或模型交互上下文。

## 七、常见问题解答 (FAQ)

#### Q1: 运行纯内存模式会影响账号安全或封号吗？
**绝对不会。** 纯内存模式 100% 不修改本地磁盘上的任何官方文件，不篡改程序数字签名。通信只在本地回环接口（127.0.0.1）进行，Google 云端服务器无法亦无权感知任何客户端本地 DOM 文本的呈现变动。

#### Q2: 官方发布新版本更新后，汉化会失效吗？
- **纯内存模式**：官方静默升级后，直接启动即可继续享受中文，完全不与官方升级产生任何文件冲突；
- **固化模式**：小工具内置跨版本自适应的 MiniAsarPatcher，官方更新覆盖后直接点击固化，0.05 秒就地为官方最新版本完成微创打补丁，永不降级冲突。

#### Q3: 自定义词典保存在哪里？
保存在您的用户数据目录 `%APPDATA%\Antigravity\user_custom_dict.json` 中，您可以通过小工具界面随时一键导出为独立 JSON 文件备份。
